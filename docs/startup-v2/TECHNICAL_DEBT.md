**Phase 0A: Baseline Audit Artifact**

## 1. Technical Debt Inventory

| ID | Severity | Category | Affected Files | Description | Business / User Impact | Recommended Future Action |
| :--- | :---: | :--- | :--- | :--- | :--- | :--- |
| **DEBT-001** | `CRITICAL` | **Persistence** | `services/api/app/repository/memory.py`, `services/registry/repository.py` | Incident and registry records are held strictly in Python dictionary memory. | Any container restart, redeploy, or scaling action wipes all logged incidents and intelligence. | Replace with SQLAlchemy ORM + PostgreSQL persistence models and Alembic migrations. |
| **DEBT-002** | `CRITICAL` | **Testing / CI** | `tests/unit/test_neo4j_*.py`, `tests/benchmark/test_benchmarks.py` | Hard import `from neo4j import AsyncGraphDatabase` at module level without checking if package is installed. | 14 test files error out during collection. Pytest cannot execute cleanly in standard environments. | Wrap neo4j imports with `try/except ImportError` and provide clean pytest skipping / mock fixtures. |
| **DEBT-003** | `CRITICAL` | **Build / Typecheck** | `apps/web/app/incidents/[id]/page.tsx:115` | Parameter `c` implicitly has an `any` type in map closure. | Next.js production build (`npm run build`) fails, blocking production deployment. | Explicitly type the counter-evidence parameter in the incident view. |
| **DEBT-004** | `HIGH` | **ML Authenticity** | `ml/payment/classifier.py`, `ml/url/classifier.py` | URL and Payment "ML" classes are actually hand-crafted heuristic linear formulas using hardcoded YAML weights. | Misleads users and enterprise partners; prone to high false-alarm rates; cannot adapt to new fraud patterns. | Clearly relabel as heuristic baseline scorers until genuine models are trained on labelled datasets. |
| **DEBT-005** | `HIGH` | **Architecture** | `services/risk_engine/unified_engine.py`, `services/pattern-engine/matcher/risk_engine.py` | Multiple competing risk scoring implementations with overlapping responsibilities. | Divergent risk scores across different API paths, resulting in conflicting defensive interventions. | Consolidate into a single canonical `UnifiedRiskEngine` under `services/risk_engine/`. |
| **DEBT-006** | `HIGH` | **Security / SSRF** | `services/investigation/orchestrator.py`, `services/investigation/url_analysis/` | URL investigation fetches external target links without robust IP address blacklisting (e.g. AWS/GCP metadata IPs, private LANs). | Risk of Server-Side Request Forgery (SSRF) and resource exhaustion attacks from malicious URLs. | Introduce strict private/reserved IP egress blocking and enforce strict HTTP client timeouts. |
| **DEBT-007** | `HIGH` | **Privacy / PII** | `packages/schemas/entities.py`, `services/api/app/main.py` | Raw phone numbers, bank accounts, UPI VPAs, and full message transcripts are processed and stored unmasked. | Violates data protection standards (DPDP Act, RBI compliance); creates severe liability if logs leak. | Introduce PII masking/hashing utilities at ingestion boundary before persistence or logging. |
| **DEBT-008** | `MEDIUM` | **Security / Auth** | `services/api/app/main.py` | All FastAPI endpoints are publicly exposed without API keys, JWT authentication, or rate limiting. | Vulnerable to automated scraping, DoS, and unauthorized bulk data ingestion. | Implement API key middleware and token bucket rate limiting on `/api/v1/*`. |
| **DEBT-009** | `MEDIUM` | **Data Integrity** | `data/raw/`, `data/processed/`, `data/synthetic/` | Core dataset directories only contain `.gitkeep` files; training and benchmark pipelines rely on external downloads. | Reproducibility requires external network access; offline development or self-contained audits fail. | Package validated benchmark datasets and version them deterministically. |
| **DEBT-010** | `MEDIUM` | **Frontend UX** | `apps/web/app/incidents/page.tsx`, `apps/web/app/campaigns/page.tsx` | Pages display hardcoded mock incidents and demo campaign cards when backend returns empty collections. | Confuses users between real intelligence and fake simulator activity. | Introduce explicit empty states with onboarding guidance rather than deceptive mock entries. |
