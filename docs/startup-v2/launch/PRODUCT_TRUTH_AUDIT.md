## 1. Absolute Truth Directives

ScamGraph AI enforces strict truthfulness across all product surfaces:
1. **Zero Fake Live Indicators**: The `LIVE` badge in Outbreak Radar and Command Center is powered strictly by backend event freshness (`radar_lag_seconds < 300`). If lag exceeds 5 minutes, the badge transitions truthfully to `DELAYED` or `STALE`.
2. **Zero Fake Counters**: No animated tickers showing fabricated "Money Saved", "Scams Prevented", or "Active Victims". Every aggregate reflects actual database query counts.
3. **Zero Random Map Pulses**: Map coordinates and campaign clusters reflect genuine observed Indian cities and regions (e.g. Mewat, Jamtara, Delhi, Bangalore) tied to actual reported incidents.
4. **Zero Fabricated Connections**: Knowledge graph nodes and correlation edges must have explicit supporting evidence; unrelated incidents sharing weak identifiers (e.g. shared bank branch) are never falsely joined into a campaign.
5. **No Guarantees of Safety**: A `LOW RISK` score is truthfully labeled as *"No threats detected in provided evidence"*; it is NEVER presented as *"Guaranteed 100% Safe"*.
6. **No Fake Recovery Guarantees**: Rescue never promises financial recovery; it provides tactical triage, reporting preparation, and explicitly warns victims against recovery-fee scammers.
