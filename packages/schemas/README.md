# packages/schemas — Shared Data Schemas

## Overview
Defines universal schemas, data models, and contracts used across services and the web client:
- Ingestion event contracts (`Event`, `MessageEvent`, `UrlClickEvent`, `PaymentIntentEvent`).
- Evidence signal definitions (`EvidenceSignal`, `SignalDimension`, `Severity`).
- Assessment output types (`RiskLevel`, `ConfidenceLevel`, `AssessmentResult`).
- Graph transfer payloads compatible with Cytoscape.js.
