# apps/web — ScamGraph AI Frontend

## Overview
Web application interface for ScamGraph AI built with:
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Visualization**: Cytoscape.js

## Key Features
- **Scam Journey Graph Visualizer**: Interactive directed graph visualizing step-by-step psychological progression leading to a payment.
- **Evidence Inspector**: Detailed breakdown of signals, weights, and confidence levels.
- **Risk & Confidence Radar**: Dual-axis assessment indicator (Risk: LOW/MED/HIGH, Confidence: LOW/MED/HIGH, or INSUFFICIENT_EVIDENCE).
- **Adaptive Intervention Simulator**: Preview of user-facing contextual friction.
