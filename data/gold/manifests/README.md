# Gold Set Manifests

Tracks immutable versioned manifests of the India Gold Standard Set (`v1.0.0.json`, `v2.0.0.json`).

Each manifest records:
- `manifest_version`
- `release_date`
- `sha256_checksum`
- `sample_count_by_language`
- `sample_count_by_scam_family`
- `hard_negatives_count`
- `audited_by`
