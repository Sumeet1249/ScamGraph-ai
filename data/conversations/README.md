# Multi-Message & Conversation Transcripts (`data/conversations/`)

## Intended Purpose
Staging directory for full-turn, multi-message victim-scammer conversation threads (WhatsApp, Telegram, SMS dialogues).

## Governance Rules
1. Never commit raw, unmasked chat logs.
2. Anonymize victim names, phone numbers, and payment details before storing.
3. Classify provenance explicitly (`REAL_ANONYMIZED`, `HUMAN_CURATED`, or `SYNTHETIC_LLM`).
